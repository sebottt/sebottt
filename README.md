### Trabajo destacado

**[firefox-default-search-anthropic](https://github.com/sebottt/firefox-default-search-anthropic)**
Análisis de una extensión de Firefox, firmada y distribuida por Mozilla, que incorporó código malicioso
mediante una actualización automática doce días después de una instalación limpia. Ingeniería inversa
del canal de mando y control, recuperación de la configuración que el operador había enviado al
navegador, y reconstrucción de la cronología a partir de los artefactos del perfil. Incluye la muestra,
los hashes y los indicadores. No existía ninguna publicación previa sobre este comportamiento.

**[Veredict_App](https://github.com/sebottt/Veredict_App)**
Plataforma web institucional para estudiantes, docentes y administradores. PHP sin framework,
JavaScript vanilla, MySQL. JWT en cookie httpOnly con guardas de rol en servidor, OAuth de Microsoft
para inicio de sesión único, desplegada en AWS tras Apache con TLS. También administro el servidor
donde corre.

**[confession-relay-bot](https://github.com/sebottt/confession-relay-bot)**
Bot de retransmisión en Python, corriendo bajo systemd en la misma infraestructura.
